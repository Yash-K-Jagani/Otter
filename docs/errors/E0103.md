# E0103 — bitwise operand is not an integer

A bitwise operator was applied to a value that is not an integer.

## Cause

`&`, `|`, `^`, `~`, `<<` and `>>` operate on integers (`int`, `i8`…`i64`,
`u8`…`u64`, `usize`). `&`, `|` and `^` also accept `bool`, where they are the
non-short-circuit logical forms. A `float`, `string`, `char`, or aggregate has
no bit pattern Yashy is willing to expose.

## Example

```yashy
fn main() {
    const x: float = 1.5;
    const y = x & 1;
}
```

```text
bits.ya:3:15
error[E0103]: cannot apply `&` to `float` and `float`
    const y = x & 1;
              ^^^^^
  docs: https://yashy.dev/errors/E0103
```

## Fix

Convert the value to an integer first with `as`, or use the arithmetic
operators for a float. A `char` converts with `to_int()`.
