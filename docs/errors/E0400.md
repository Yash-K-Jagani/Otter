# E0400 — const reassignment

A `const` binding is assigned after its declaration.

## Cause

`const` declares an immutable binding. Assigning to it, to a field of it, or to
an array element of it is rejected; `let` declares the mutable form.

## Example

```yashy
fn main() {
    const x = 1;
    x = 2;
}
```

```text
const.ya:3:5
error[E0400]: cannot assign to `x`, which is immutable
    x = 2;
    ^
note: use `let` for a mutable binding
```

## Fix

Declare the binding with `let` when it changes. If it should not change, remove
the assignment.
