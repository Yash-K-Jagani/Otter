# E0001 — unknown name

The compiler could not find a value or function with that name.

## Cause

A name is used before it is declared, outside the block that declares it, or
with a typo. The checker looks in the current block, then outward through the
enclosing blocks and the imported modules.

## Example

```yashy
fn main() {
    const total = 3;
    print(totl);
}
```

```text
misspell.ya:3:11
error[E0001]: cannot find value `totl` in this scope
    print(totl);
          ^^^^ did you mean `total`?
  docs: https://yashy.dev/errors/E0001
```

## Fix

Spell the name as it is declared, declare it before use, or import the module
that declares it. A close misspelling gets a `did you mean` label; a name that
is simply absent gets the same error without one.
