# E0201 — missing field

A struct literal or a named-variant pattern leaves out a field.

## Cause

Every field of a struct is required in a literal, and every named field of a
variant is required in a pattern. There is no default value and no `..` rest
pattern in R1.

## Example

```yashy
struct Point {
    x: int,
    y: int,
}

fn main() {
    const p = Point { x: 1 };
}
```

```text
fields.ya:7:15
error[E0201]: missing field `y` in struct `Point`
    const p = Point { x: 1 };
              ^^^^^^^^^^^^^^^
```

## Fix

Write the missing field, or remove it from the declaration if the type does not
need it.
