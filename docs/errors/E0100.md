# E0100 — type mismatch

An expression's type does not match the type its context requires.

## Cause

The context is a `const`/`let` annotation, a function argument, a `return`, an
`if`/`while` condition, a struct field, or an array element. Yashy has no
implicit conversion between the four scalar types.

## Example

```yashy
fn main() {
    const answer: int = "forty-two";
}
```

```text
mismatch.ya:2:25
error[E0100]: expected `int`, found `string`
    const answer: int = "forty-two";
                        ^^^^^^^^^^^
  docs: https://yashy.dev/errors/E0100
```

## Fix

Make the expression produce the required type, or change the annotation to the
type the expression already has. For a `Result` used where its success value is
expected, see E0300.
