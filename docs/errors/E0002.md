# E0002 — unknown type

The compiler could not find a type with that name.

## Cause

A type annotation, a struct field, a function parameter, or a `switch` pattern
names a type that is not declared or imported. Built-in types are `int`,
`float`, `bool`, `string`, `char`, `void`, and the pointer and fixed-array
forms.

## Example

```yashy
fn main() {
    const x: Nope = 1;
}
```

```text
types.ya:2:14
error[E0002]: cannot find type `Nope`
    const x: Nope = 1;
             ^^^^
  docs: https://yashy.dev/errors/E0002
```

## Fix

Use a declared type, or declare the type before the code that names it. A close
misspelling gets a `did you mean` label naming the nearest declared or built-in
type.
