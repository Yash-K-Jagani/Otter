# E1000 — leaked linear value

A linear value is never released.

## Cause

`alloc`, `slice_new`, `map_new`, `mutex_new` and `chan_new` each return a
linear value: one binding owns it, and the allocation lives until that binding
calls `.free()`. When the binding's scope ends without a release, the value is
still live and nothing can reach it again — the memory is leaked.

The verifier checks this before the program runs. A binding counts as released
when it is freed, moved, returned, passed to a call, stored in a struct, slice,
array or tuple, or overwritten by an assignment. Anything that hands the value
to someone else counts, because the owner has changed even if the release
happens elsewhere.

## Example

```yashy
fn main() {
    let buf = alloc(16);
}
```

```text
leak.ya:2:5
error[E1000]: linear value `buf` is never released
    let buf = alloc(16);
    ^^^^^^^^^^^^^^^^^^^
  docs: https://yashy.dev/errors/E1000
```

## Fix

Release the value, or hand it to something that will. `defer` is the usual
answer: it frees at scope exit, after the last use.

```yashy
fn main() {
    let buf = alloc(16);
    defer { buf.free(); }
}
```

Returning the value is also a release, because the caller becomes the owner:

```yashy
fn make() -> *mut int {
    let buf = alloc(16);
    return buf;
}
```

`defer` registers where it is written and is checked there, so write it after
the last statement that reads the value — registering it first makes the value
count as moved for the rest of the scope.

## A viewed array is a warning, not an error

A `[]T` that has been viewed cannot be released: `xs.free()` is refused while
the view is alive, and a view lives until the function returns. The language
therefore gives no way to release that array, so the verifier reports it as a
**warning** with the same code:

```text
warning[E1000]: linear value `xs` is borrowed by a view and cannot be released
```

The program still builds. To avoid the leak, use a fixed array `[T; N]` — its
storage is in the frame, so there is nothing to free — or copy the elements
into a `[]T` you own and release that.
