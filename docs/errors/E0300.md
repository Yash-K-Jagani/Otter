# E0300 — missing `?`

A `Result` is used where its success value is expected.

## Cause

A function that returns `Result[T, E]` produces the whole result, not `T`. Using
the call as a `T` -- in an annotated binding, an argument, a return, or an
operator -- is a type mismatch with a specific fix: propagate the error with
`?`, or match both variants.

## Example

```yashy
fn parse() -> Result[int, string] {
    return Ok(7);
}

fn main() {
    const n: int = parse();
}
```

```text
question.ya:6:20
error[E0300]: expected `int`, found `Result[int, string]`
    const n: int = parse();
                   ^^^^^^^
note: use `?` to propagate the error, or match the `Result`
  docs: https://yashy.dev/errors/E0300
```

## Fix

Write `parse()?` inside a function that returns a compatible `Result`, or use a
`switch` to handle `Ok` and `Err` explicitly.
