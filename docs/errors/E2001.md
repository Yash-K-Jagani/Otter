# E2001 — unused import

An `import` is never used.

## Cause

An import that is never used pulls a module into the program for no reason:
it costs compile time, it costs the reader's attention, and it usually means
a dependency was left behind after a refactor. The warning fires when an
imported name never appears in the program.

An import is exempt when the module has a side effect the checker records:
initialising a global, registering a handler, or otherwise doing work at
load time. The checker's effect table is the authority on which imports are
pure.

## Example

```yashy
import math;

fn main() {
    print(1);
}
```

```text
main.ya:1:8
warning[E2001]: `math` is never used
    import math;
           ^^^^ unused import
  docs: https://yashy.dev/errors/E2001
```

## Fix

Remove the import, or use the name it brings in. If the module is imported
for its side effects, the checker already knows and the warning does not fire.
