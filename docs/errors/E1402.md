# E1402 — race

A bare linear value is shared across a thread boundary.

## Cause

A value captured by a closure that is handed to `thread_spawn` must be safe to
share between threads. A `Mutex`, a `Channel`, a `string` (atomic refcounts
when the program uses threads) or any `Copy` type qualifies. A bare linear
pointer does not: two threads would both believe they own it, and one of them
releasing it would leave the other reading freed memory.

## Example

```yashy
fn main() {
    let buf = alloc(16);
    let handle = thread_spawn(|() -> int { buf[0] = 1; return 0; });
    thread_join(handle);
}
```

```text
main.ya:3:30
error[E1402]: `buf` is shared across a thread boundary without a `Mutex`
  docs: https://yashy.dev/errors/E1402
```

## Fix

Wrap the value in a `Mutex`, or pass it through a `Channel`. A `string` or a
`Copy` value needs no wrapper.
