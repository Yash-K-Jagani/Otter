# E2000 — unused binding

A `const` or `let` binding is never read.

## Cause

A binding that is never read is dead code: it costs storage, it costs the
reader's attention, and it usually means a value was computed and then
forgotten. The warning fires when a `const` or `let` binding's name does not
appear on the right-hand side of any expression in its scope.

A binding whose name is `_` or starts with `_` is exempt: `_` is the
idiomatic "I am discarding this" and `_unused` is the idiomatic "I know this
is unused and I am saying so".

## Example

```yashy
fn main() {
    const x = 1;
}
```

```text
main.ya:2:11
warning[E2000]: `x` is never read
    const x = 1;
          ^ unused binding
  docs: https://yashy.dev/errors/E2000
```

## Fix

Read the binding, or remove it. If the binding exists for its side effect
(such as an allocation whose pointer is intentionally leaked), rename it
with a leading underscore to say so:

```yashy
fn main() {
    const _buf = alloc(16);
}
```
