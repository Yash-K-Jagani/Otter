# E2002 — unreachable code

A statement cannot be reached.

## Cause

Code that follows an unconditional `return`, `break`, `continue`, `panic` or
`os.exit` never runs: the control flow has already left the function or the
loop. The warning fires on the first statement after such a terminator.

The warning is conservative: it fires only when the terminator is
unconditional. A `return` inside an `if` does not make the following
statement unreachable, because the other branch falls through.

## Example

```yashy
fn f() -> int {
    return 1;
    print(2);
}
```

```text
main.ya:3:5
warning[E2002]: unreachable code
    print(2);
    ^^^^^^^^^ this statement can never run
  docs: https://yashy.dev/errors/E2002
```

## Fix

Remove the unreachable statement, or move it before the terminator. If the
code is intentionally unreachable (for example, a guard that documents an
invariant), suppress the warning with `--allow warnings` or rename the file
as generated.
