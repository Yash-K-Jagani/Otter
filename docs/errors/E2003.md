# E2003 — unused parameter

A function parameter is never read.

## Cause

A parameter that is never read is dead code: it is part of the function's
contract but the body does not use it. The warning fires when a parameter's
name does not appear on the right-hand side of any expression in the function
body.

A parameter whose name is `_` or starts with `_` is exempt: `_` is the
idiomatic "I am ignoring this" and `_unused` is the idiomatic "I know this
is unused and I am saying so".

## Example

```yashy
fn f(x: int) -> int {
    return 0;
}
```

```text
main.ya:1:6
warning[E2003]: `x` is never read
    fn f(x: int) -> int {
         ^ unused parameter
  docs: https://yashy.dev/errors/E2003
```

## Fix

Read the parameter, or remove it from the signature. If the parameter exists
for its type (for example, a trait method that must match a shape), rename
it with a leading underscore to say so:

```yashy
fn f(_x: int) -> int {
    return 0;
}
```
