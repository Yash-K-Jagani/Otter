# E0900 — duplicate linker symbol

One symbol is claimed twice and the two claims cannot both be true.

## Cause

An `extern` declaration has two names: the Yashy name the program writes, and
the symbol the linker resolves. The symbol is the declaration's name unless
`link_name` says otherwise. Two declarations may share a symbol only if their
parameter and return types match — then they are the same C function described
twice, and the program emits one `declare` and calls it from both names. When
the signatures differ, one of the two is lying about what the C function is, and
there is no answer that is right for both call sites.

The same rule covers a program that both defines a function and declares a C
function of the same symbol. A Yashy function's linker symbol is its name, and
the C functions the program declares live in that one flat namespace. If the two
were one symbol, the declaration's call would reach the Yashy body — a wrapper
around a C function of its own name would call itself — and the emitter would
write a `declare` and a `define` for one name, which `clang` rejects.

## Example

```yashy
extern "C" {
    unsafe fn getpid() -> i32;
    unsafe fn process_id() -> i64 link_name "getpid";
}

fn main() {
    print(getpid());
    println("");
}
```

```text
    unsafe fn process_id() -> i64 link_name "getpid";
    ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

```

The second shape, a symbol the program also defines:

```yashy
extern "C" link "m" {
    unsafe fn c_sqrt(x: f64) -> f64 link_name "sqrt";
}

fn sqrt(x: float) -> float {
    return unsafe c_sqrt(x);
}

fn main() {
    print(sqrt(9.0));
}
```

```text
dup.ya:2:5
error[E0900]: `c_sqrt` resolves to symbol `sqrt`, which this program also defines: a call would reach the Yashy function instead of the C one
    unsafe fn c_sqrt(x: f64) -> f64 link_name "sqrt";
    ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
  docs: https://yashy.dev/errors/E0900
```

## Fix

For two declarations, give them the same signature, or point one of them at a
different symbol. If the C function really does return different types in
different contexts, it is two functions and needs two `link_name`s.

For a declaration and a definition, rename one of them. The Yashy function keeps
the name the program calls; the C function is reached through a declaration
whose Yashy name differs, so the two symbols stay distinct.
