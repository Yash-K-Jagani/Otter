# E0104 — bitwise operands have different types

A bitwise operator was applied to two integers of different types.

## Cause

Yashy has no implicit widening. `1u8 & 1i64` is two different integer types, and
the result would have to be one of them. Mixing `int` and a C width, or two C
widths, is the same mistake.

## Example

```yashy
fn main() {
    const a: u8 = 1;
    const b: int = 1;
    const c = a & b;
}
```

```text
bits.ya:4:15
error[E0104]: cannot apply `&` to `u8` and `int`
    const c = a & b;
              ^^^^^
  docs: https://yashy.dev/errors/E0104
```

## Fix

Cast one operand so both have the same type: `a as int & b`, or
`a & (b as u8)` when the narrower type is the intended result.
