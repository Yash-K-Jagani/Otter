# E0105 — shift count is out of range

A shift operator (`<<` or `>>`) was applied with a count that is outside the
valid range for the shifted type.

## Cause

A shift count must be within `0..bits` where `bits` is the bit width of the
shifted type:
- `i64` and `usize` have 64 bits
- `u8` has 8 bits, `u16` has 16 bits, etc.

Writing `1 << 64` or `1u8 << 8` is always a mistake. A negative count also
counts as out of range.

## Example

```yashy
fn main() {
    const x: int = 1 << 64;
}
```

```text
bits.ya:2:15
error[E0105]: shift count out of range: `64` is not in `0..64` for `int`
    const x: int = 1 << 64;
                ^^^^^
  docs: https://yashy.dev/errors/E0105
```

## Fix

Use a value that is within the type's bit width, or cast to a wider type
first. If the count is dynamic and might be out of range, the runtime check
will insert a `yashy_panic_shift` call.
