# E1301 — unsafe call

An unsafe call outside an unsafe function.

## Cause

A call marked `unsafe` (typically an `extern` C function) may only appear
inside a function declared `unsafe`. A `pure` or `io` function that calls
an unsafe function must declare itself `unsafe`.

## Example

```yashy
fn f() {
    unsafe_c_fn();
}
```

```text
main.ya:2:5
error[E1301]: `unsafe_c_fn` is an unsafe call outside an `unsafe fn`
    unsafe_c_fn();
    ^^^^^^^^^^^^^
  docs: https://yashy.dev/errors/E1301
```

## Fix

Declare the calling function `unsafe`, or remove the unsafe call.
