# E0600 — non-exhaustive match

A `switch` does not cover every case.

## Cause

A `switch` over an enum must name every variant, and a `switch` over a
non-enum type must have a `default` arm. A guarded arm (`case A if c`) does not
count as covering `A`, because the guard can be false.

## Example

```yashy
enum Color {
    Red,
    Green,
}

fn code(c: Color) -> int {
    return switch c {
        case Red { 1 }
    };
}
```

```text
match.ya:8:12
error[E0600]: switch is not exhaustive: missing case `Green`
    return switch c {
           ^^^^^^^^
```

## Fix

Add the missing `case` arms, or add a `default` arm when every remaining value
should take the same path.
