# E1401 — use after close

A resource is used after it has been released.

## Cause

Once a resource is in a terminal state (`Freed` or `Closed`) it can no longer be
used: a freed pointer cannot be read or written, a closed channel cannot send
or receive. Using it anyway is `E1401`.

## Example

```yashy
fn main() {
    let c = chan_new(4);
    chan_close(c);
    chan_send(c, 1);
}
```

```text
main.ya:4:5
error[E1401]: `c` is used after it has been released
    chan_send(c, 1);
    ^^^^^^^^^^^^^^^^
  docs: https://yashy.dev/errors/E1401
```

## Fix

Do the work before releasing the resource, or re-open a fresh one.
