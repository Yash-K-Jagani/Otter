# E0200 — unknown field

A struct or enum variant has no field with that name.

## Cause

Field access (`p.y`), a struct literal, a variant pattern, or a field assignment
names a field that is not declared on the type.

## Example

```yashy
struct Point {
    x: int,
    y: int,
}

fn main() {
    const p = Point { x: 1, y: 2 };
    print(p.z);
}
```

```text
fields.ya:8:13
error[E0200]: struct `Point` has no field `z`
    print(p.z);
            ^
```

## Fix

Use a declared field. A close misspelling gets a `did you mean` label naming the
nearest field.
