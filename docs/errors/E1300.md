# E1300 — effect exceeded

A declared effect is exceeded by the body.

## Cause

A function declared as `pure`, `io`, or `unsafe` must not exceed its
declaration. A `pure` function may not perform IO or use unsafe operations.
An `io` function may not use unsafe operations without declaring `unsafe`.

## Example

```yashy
pure fn f() {
    println("x");
}
```

```text
main.ya:1:1
error[E1300]: declared `pure`, but the body performs `io`
    pure fn f() {
    ^^^^^^^^^^^^^
  docs: https://yashy.dev/errors/E1300
```

## Fix

Remove the declaration, or remove the offending call. A function with no
declaration has its effect inferred automatically.
