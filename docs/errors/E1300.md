# E1300 — effect exceeded

A declared effect is exceeded by the function's body.

## Cause

Effects are inferred for every function, bottom-up over the call graph, and a
declaration is a promise that the inference must not exceed:

- `pure fn` — the body performs no IO and makes no unsafe call;
- `io fn` — the body may perform IO, and makes no unsafe call;
- `unsafe fn` — the body may do anything;
- `async fn` — the body may perform IO.

The promise may be *looser* than the body: `io fn` that happens not to print
today is legal, because the declaration says what the function may do, not what
it does. A declaration that is *stricter* than the body is the error.

An unannotated function is inferred, never rejected. Effects are opt-in: a
program with no `pure`, `io` or `unsafe` on its functions compiles exactly as
it did before effects existed.

## Example

```yashy
io fn g() {
    println("x");
}

pure fn h() {
    g();
}
```

```text
main.ya:5:6
error[E1300]: declared `pure`, but the body performs `io`
pure fn h() {
     ^^^^^^^^
  = note: remove `pure`, or remove the IO call
  docs: https://yashy.dev/errors/E1300
```

## Fix

Remove the declaration and let the effect be inferred, or make the body keep
the promise:

```yashy
fn h() {
    g();
}
```

When the body makes an `unsafe` call itself, the call site is reported as
[E1301](E1301.md) instead, so one mistake produces one diagnostic.
