# E0500 — moved value

A linear value is used after it was moved or freed.

## Cause

`alloc` returns a linear pointer. Passing it to a function that takes ownership,
`move`-ing it into a new binding, or calling `.free()` spends it. A second use
would free the same allocation twice, so the checker rejects it.

## Example

```yashy
fn main() {
    let buf = alloc(16);
    buf.free();
    buf.free();
}
```

```text
moved.ya:4:5
error[E0500]: value `buf` has already been moved
    buf.free();
    ^^^
```

## Fix

Use the value once, or hand it to exactly one owner. `defer buf.free();` frees
it at scope exit without a second call.
