# E0700 — wrong argument count

A call passes a different number of arguments than the function declares.

## Cause

The checker counts the arguments and compares them with the parameter list. A
method call counts only the arguments after the receiver; the receiver is the
first parameter.

## Example

```yashy
fn add(a: int, b: int) -> int {
    return a + b;
}

fn main() {
    print(add(1));
}
```

```text
arity.ya:6:11
error[E0700]: expected 2 arguments, found 1
    print(add(1));
          ^^^^^^
```

## Fix

Pass every argument the function declares. If the function should accept a
variable number, give it the fixed part and pass an array or map for the rest.
